# 👋 Hi, I'm Arash

**I'm a crypto and fintech product leader. Since April 2026 I've been building hands-on: a payments startup and a handful of AI applications.**

Before that I was Director of Product at Polygon Labs.

## 🚀 What I'm building

- 💸 **[Tavo](https://tavohq.com)**: the payment layer for chat-native commerce. A merchant sends a payment request in the chat thread, the customer confirms with one tap, and it settles in seconds. Non-custodial by design. It's in stealth and I'm building it solo.
- ✍️ **[Faircopy](https://faircopy.me)**: rewrites your LinkedIn profile so it still sounds like you. A fabrication auditor reads the rewrite against your original and flags any claim it can't find there.
- 🧭 **[Fieldbook](https://github.com/arash009/fieldbook)**: turns an itinerary file into an offline, encrypted phone app. No framework, no dependencies, 57 tests. I built it for my own family trip. [Try the demo](https://arash009.github.io/fieldbook/#demo).
- 🍽️ **Plateful**: a meal planning web app for parents, built on a local recipe databank.
- 🧪 **CareerBrand AI**: an eval harness that tests whether a structured prompt pipeline beats naive prompting for LinkedIn rewrites.

## 🛠️ How I build

- 🤖 I build with AI coding agents every day. I set the product direction and the constraints, and I review each step.
- 📝 I write the spec and the tests before the code.
- 📏 I write evals to measure quality.
